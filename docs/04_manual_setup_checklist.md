# 코딩 전 수동 준비 체크리스트

아래 항목은 사용자가 직접 준비하는 항목입니다. 현재 단계에서는 계정 생성만 하고 실제 키는 코드에 넣지 않습니다.

## 필수

- [ ] VS Code 설치 및 최신 업데이트
- [ ] Node.js 20 이상 LTS 설치
- [ ] Git 설치
- [ ] Codex CLI에서 `codex --version` 확인
- [ ] GitHub 계정 준비
- [ ] 작업 폴더를 OneDrive·공유 폴더가 아닌 일반 로컬 폴더에 생성

## 권장 VS Code 확장

- [ ] ESLint
- [ ] Prettier - Code formatter
- [ ] Tailwind CSS IntelliSense
- [ ] GitLens (선택)

## 2단계에서 준비할 계정

- [ ] Supabase 계정 및 새 프로젝트
- [ ] Vercel 계정 또는 배포 서비스 계정

## 나중에 준비할 항목

- [ ] SMS 발송업체 계정: 실제 SMS 보완 알림을 켤 때만
- [ ] 학원 도메인: 외부 공개 배포 직전
- [ ] 개인정보처리방침 최종 문안: 학부모 초대 기능 직전
- [ ] 실제 테스트용 교사·보호자·학생 가상 데이터

## 절대 하지 않을 것

- API 키, 비밀번호, 휴대전화 번호를 GitHub에 올리지 않는다.
- `.env.local` 파일을 Codex CLI 대화창이나 화면 캡처에 그대로 올리지 않는다.
- 실제 학생·보호자 개인정보로 첫 테스트를 하지 않는다.
- 기본 권한·RLS 검증 전에는 외부 학부모에게 링크를 발송하지 않는다.
